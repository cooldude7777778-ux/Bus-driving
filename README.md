# 🚌 Трэш-симулятор водителя автобуса
3D-игра в одном `index.html` на Three.js (r128). Только для телефона, только в горизонтали.

**Запуск:** залей папку в репозиторий → Settings → Pages → ветка `main` / root. Открой ссылку на телефоне и тапни по экрану.

**Three.js:** сначала грузится локальный `three.min.js` (если положишь рядом), затем cdnjs, затем jsDelivr.

**Управление:** джойстик слева (газ/тормоз/руль), КАМЕРА (кабина / бампер), ДВЕРИ (на зелёных остановках), ОРАТЬ! (лечит ребёнка и бузотёров), УБРАТЬ ТЕЛЕФОН! (3 раза — и девушка вылетает на обочину). На ПК: WASD / стрелки.

**Озвучка:** без TTS — бессмысленная «болтовня» через Web Audio (как в Undertale), смысл — в субтитрах.
